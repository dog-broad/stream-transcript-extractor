🎯 How to Use

  1. Open the Stream Recording

    Navigate to the Microsoft Stream / SharePoint recording URL in your browser. The URL typically looks like https://your-org.sharepoint.com/...stream.aspx?id=...

  2. Open the Transcript Pane

    Click the "Transcript" button in the video player toolbar. Wait 2-3 seconds for the first entries to appear.

  3. Click the Bookmarklet

    Click "📜 Extract Transcript" in your bookmarks bar. A progress overlay will appear showing extraction status.

  4. View Results in New Tab

    A new tab opens with the complete transcript — searchable, color-coded by speaker, and downloadable in multiple formats.

🛠️ Troubleshooting

Nothing happens when I click the bookmarklet

Chrome may have stripped the javascript: prefix. Edit the bookmark and confirm the URL starts with javascript:. Also ensure you're on the Stream page, not a blank tab.

Alert says "Transcript pane not found"

The transcript panel must be open and visible before clicking. Click the "Transcript" button on the video player first, wait for entries to appear.

Only partial entries extracted

For very long recordings (1hr+), the script runs 3 scroll passes by default which covers most cases. If entries are still missing, try running the bookmarklet again — it will re-extract.

New tab doesn't open / gets blocked

Your browser's popup blocker may have blocked it. Look for a blocked popup icon in the address bar and allow popups for this site.

Script fails to load

Check if your network/VPN blocks GitHub Gist URLs. If so, you can copy the script source and paste it directly into the browser console (F12 → Console).

⚙️ How It Works

Microsoft Stream's transcript pane uses a virtualized list (lazy loading) — only rendering entries visible in the viewport. This means you can never select-all or copy the full transcript. The download button is also permission-locked if you're not the recording owner.

  1. Auto-Scroll

    The script programmatically scrolls the transcript pane from top to bottom in small increments, forcing the virtualized list to render each batch of entries.

  2. Collect Entries

    On each scroll step, it reads the DOM for newly rendered items — extracting speaker name, timestamp, and transcript text. Uses a Map keyed by index to deduplicate.

  3. Multiple Passes

    Runs 3 complete scroll passes for reliability, since the virtualized list may unload previously rendered items. Each pass fills gaps from prior passes.

  4. Generate Results Page

    Constructs a self-contained HTML page with the extracted data embedded, opens it in a new tab. The page has its own search, filtering, and export functionality.
